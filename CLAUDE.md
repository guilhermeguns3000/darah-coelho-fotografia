# Projeto: Site Darah Coelho Fotografia

## O projeto
Site WordPress da fotógrafa Darah Coelho, localizada em Goiânia, GO.
URL: https://darahcoelhofotografia.com.br/
Objetivo: alcançar a primeira posição do Google para múltiplas keywords de fotografia em Goiânia.

## Estado atual do site (auditado em maio/2026)
- Apenas 1 página indexada pelo Google (homepage)
- Página de serviços (/servicos/) completamente vazia
- Nenhuma meta description em nenhuma página
- Zero schema markup
- Todas as imagens com nomes IMG_XXXX.jpeg sem alt text
- Stack técnico: WordPress + provavelmente Elementor
- Hospedagem: desconhecida, provavelmente shared hosting

## Serviços da fotógrafa
1. Ensaio Pessoal / Book (já tem página: /book-fotografico-goiania/)
2. Ensaio de Moda / Book de Moda
3. Fotografia de Produto / Marketplace (e-commerce, catálogos)
4. Casamento
5. Gestante
6. Newborn / Bebê
7. Família
8. Batismo
9. Eventos Corporativos
10. Videomaker

## Fluxo de trabalho padrão para criar uma nova página
1. `/fotografo-palavras-chave [serviço]` → obter keywords
2. `/fotografo-pagina [serviço]` → gerar conteúdo completo
3. Publicar no WordPress
4. `/fotografo-imagem [serviço]` → otimizar imagem hero
5. Solicitar indexação no Google Search Console

## Decisões técnicas tomadas
- **WordPress**: manter, mas migrar para Hostinger Business + LiteSpeed Cache + RankMath
- **Elementor**: trocar por Kadence (tema leve) quando possível
- **CDN**: Cloudflare (plano gratuito)
- **Imagens**: ShortPixel para compressão automática em lote
- **SEO plugin**: RankMath (Free ou Pro)

## Prioridade de execução
Fase 1 (Quick Wins) → Fase 2 (Páginas de Serviço) → Fase 3 (Autoridade) → Fase 4 (Mensal)
Ver detalhes em: `/fotografo-sistema`
